# Folio

Gera um currículo limpo a partir do PDF (ou ZIP) exportado do LinkedIn.

## Como usar

```bash
npm install
npm run dev
```

Abra o endereço do Vite, depois:

1. No LinkedIn, abra seu perfil → **Recursos** → **Salvar em PDF**
2. Solte o arquivo na página
3. Escolha um layout (Clássico, Moderno, Sidebar, Minimal ou Editorial)
4. Ajuste o texto se precisar e baixe o PDF

Também aceita o ZIP de **Configurações → Dados da conta → Obter uma cópia dos seus dados**.
